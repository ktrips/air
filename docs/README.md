# Google MapとClaudeで作るWebアプリ開発完全ガイド

## 本書について

このKindle本は、Google Maps APIとClaude（AI）を活用したWebアプリケーション開発について、実践的なガイドです。

実例としてトリップ管理アプリ「AIR」の開発プロセスを通じて、以下を学ぶことができます：

- Google Maps APIの統合方法
- Claude APIを使用したAI機能の実装
- Firebase Firestoreでのデータ管理
- Google Authenticationの実装
- リアルタイムデータ同期
- プロダクション環境へのデプロイ

## 対象読者

- JavaScript/HTMLの基本知識がある開発者
- Google Maps APIを初めて使う人
- Claude APIを使用したAI統合に興味のある人
- フルスタックWebアプリ開発を学びたい人

1. **第1章: はじめに**

6. **第6章: Firebaseとの連携**

   - 次のステップ

## 使用技術スタック

- **フロントエンド**: HTML5, CSS3, Vanilla JavaScript
- **マップ**: Google Maps JavaScript API
- **AI**: Claude API (Anthropic)
- **バックエンド/Database**: Firebase Firestore
- **認証**: Google Authentication
- **ホスティング**: Firebase Hosting
- **その他**: Google Cloud Platform
